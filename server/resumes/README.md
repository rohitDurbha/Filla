# Your resumes live here

This folder is gitignored because it holds personal data.

Put these five files here before starting the server.

- `data_science.tex`
- `data_analytics.tex`
- `research.tex`
- `software_engineering.tex`
- `rules.md` (your written rules for how Claude may tailor a resume)

The filenames map to tracks in `config.yaml`. Rename them there if you
prefer different names.
